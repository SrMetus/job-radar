A focused backend portfolio project with a lightweight web interface. Two external sources, a shared data model, and a straightforward way to browse.

Look under the hood ↗
01

Collect & normalize

Remotive and Python.org offers flow through shared normalization and URL deduplication into PostgreSQL.

02

A score you can explain

Each 0–100 score reflects technology keywords, title relevance, seniority, and remote status for the target profile. Deterministic rules, not AI or a probability of being hired.

03

A practical foundation

FastAPI, SQLAlchemy and Alembic, packaged with Docker. Automated tests run through GitHub Actions; import scheduling stays external.
